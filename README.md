## 📌 Project Overview

An interactive laboratory experimenting with audio-visual synthesis, real-time canvas rendering, particle systems, and generative web experiences.

---

## 🚀 Key Features

- **Audio Reactivity:** Real-time frequency spectrum visualizers with Web Audio analyzer nodes.
- **Particle Dynamics:** GPU-accelerated canvas animations with physics interactions.

## 🚦 Getting Started

### 1. Clone the Repository
`ash
git clone https://github.com/chilkotiKartik/interactive-media-lab.git
cd interactive-media-lab
`

### 2. Install Dependencies
`ash
npm install
`

### 3. Run Development Server
`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
