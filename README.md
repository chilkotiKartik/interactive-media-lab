## 🎯 Overview

**LAB Smoky** is a visually captivating and creatively engineered web experience, showcasing **next-level frontend innovation**, **youth-focused inspiration**, and **emotionally engaging storytelling**.

This project acts as a **creative lab** — a portfolio, an exhibition, and a playground for UI/UX excellence. With immersive visuals, floating glass panels, soft blurs, and bold headlines, it leaves a lasting impression on every visitor.

---

## ✨ Core Highlights

- 🧪 **Experimental Design**: Hero animations, hover reveals, and depth layering.
- 🌫️ **Blur & Glassmorphism**: Stylish frosted-glass cards and overlays.
- 🖼️ **Poster Showcase**: Eye-catching visual scroll zones with subtle transitions.
- 🧭 **Smooth Navigation**: Scroll-driven and section-wise storytelling.
- 📱 **Fully Responsive**: Mobile-first and tablet-friendly.
- 💡 **Inspiration for Creators**: Ideal for innovation labs, portfolio pages, or exhibition sites.

## ⚙️ Local Setup

To run this project locally:

```bash
git clone https://github.com/chilkotiKartik/lab-smoky.git
cd lab-smoky

# Install dependencies
npm install

# Start development server
npm run dev
````
